# Contributing to A-Society

A-Society is in early development, and its core design is still settling. For now it accepts one kind of pull request: **feedback reports**.

## Feedback reports: welcome

After a flow, the runtime can generate a feedback report on what worked and what didn't. Sharing it is how A-Society learns from projects other than its own.

- A feedback pull request adds one report file to the `feedback/` folder and changes nothing else.
- Review and redact the report first. The pull request is public.
- Follow [Submitting a feedback report](runtime/INVOCATION.md#submitting-a-feedback-report) for the exact steps. They work with or without push access to this repository.

## Bugs and ideas: open an issue

If you have found a bug or have a concrete suggestion, open an issue. Issues are read and considered.

## Code and documentation changes: not yet

Pull requests that change code or documentation are not accepted yet. The foundation is still moving, and outside changes now would create more friction than value, for contributors and for the project. When that changes, this file will say so.
